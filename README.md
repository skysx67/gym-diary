# Дневник зала — Telegram Mini App + бот

Мини-приложение для Telegram: дневник тренировок.
Недели (1–4) сверху, дни (Пн/Ср/Пт) слева, справа — упражнения.

**Логика:** программу (упражнения на Пн/Ср/Пт) задаёшь **один раз** — она автоматически
повторяется во всех неделях. Вес переносится с прошлой недели, повторения вписываешь заново.
Название упражнения можно переименовать (правка действует на все недели), есть кнопка удаления.

## Важно понимать про Telegram Mini App
«Мини-приложение» в Telegram — это **HTML-страница на HTTPS**, которую Telegram открывает
внутри себя. Другого формата нет. Файл `index.html` — это и есть мини-приложение (в нём уже
подключён Telegram Web App SDK). Чтобы кнопка «Открыть» его запускала, нужно:
1. выложить `index.html` в интернет по **HTTPS**;
2. привязать эту ссылку к боту.

## Файлы
- `index.html` — само мини-приложение (один файл, без сборки, данные в `localStorage`).
- `bot.js` — бот: ставит кнопку «Открыть» и отвечает на `/start` (Node.js, без зависимостей).
- `package.json` — для запуска бота (`npm start`).

## Шаг 1. Отозвать засвеченный токен
Старый токен попал в переписку — он скомпрометирован. В [@BotFather](https://t.me/BotFather):
`/revoke` → выбрать бота → получить **новый** токен. Имя бота (@username) при этом не меняется.

## Шаг 2. Выложить `index.html` по HTTPS (GitHub Pages, бесплатно)
1. Завести аккаунт на github.com (если нет).
2. Создать репозиторий, загрузить в него `index.html`.
3. Settings → Pages → Branch: `main`, папка `/root` → Save.
4. Через пару минут появится ссылка вида `https://ТВОЙ_ЛОГИН.github.io/ИМЯ_РЕПО/`.
   Проверь, что она открывается в браузере.

(Альтернативы: Netlify Drop, Vercel, Cloudflare Pages — любой статический HTTPS-хостинг.)

## Шаг 3а. Кнопка «Открыть» (самый простой путь, без запуска кода)
В [@BotFather](https://t.me/BotFather):
`/mybots` → бот → **Bot Settings** → **Menu Button** → вставить ссылку из шага 2.
Готово: в чате с ботом слева снизу появится кнопка, открывающая мини-приложение.

## Шаг 3б. (Опционально) Приветствие на /start через bot.js
Чтобы бот на `/start` присылал сообщение с кнопкой — запусти `bot.js`.
Нужен установленный Node.js 18+.

Windows PowerShell:
```powershell
$env:BOT_TOKEN="НОВЫЙ_ТОКЕН"
$env:WEBAPP_URL="https://твоя-ссылка-из-шага-2/"
node bot.js
```

Бот при старте:
- напишет своё имя (@username) — значит токен рабочий;
- сам поставит кнопку «Открыть» (можно не делать шаг 3а);
- начнёт отвечать на `/start`.

Пока `bot.js` запущен — работает `/start`. Кнопка «Открыть» работает всегда
(она хранится на стороне Telegram), даже когда бот выключен.

Чтобы `/start` работал постоянно — bot.js нужно держать запущенным (свой ПК/сервер,
либо бесплатный хостинг вроде Render/Railway).

## Локальная проверка приложения (в обычном браузере)
```bash
python -m http.server 5177
```
Открыть `http://localhost:5177/index.html`. Всё работает и вне Telegram
(тема Telegram подхватывается только внутри Telegram, в браузере — тёмная по умолчанию).
Внимание: `localhost` **не** годится для самого Telegram — там нужен публичный HTTPS (шаг 2).

## Про данные
Хранятся в `localStorage` того браузера/устройства, где открыто приложение
(внутри Telegram — его встроенный браузер). При смене устройства не переносятся.
Если позже захочешь синхронизацию между устройствами — переведём хранение на
Telegram CloudStorage (тоже без бэкенда).
