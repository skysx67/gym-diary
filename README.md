# Дневник зала — Telegram Mini App + бот

Мини-приложение для Telegram: дневник тренировок в зале.

**Концепция:**
- **Календарь-лента дней** (сегодня по центру, прокрутка вперёд/назад). Дни с тренировкой отмечены точкой.
- **Свои тренировки-шаблоны** (вкладка «Тренировки»): создаёшь тренировку = список упражнений.
- Тап по дню → **выбор тренировки** → в карточке дня вписываешь на каждое упражнение вес,
  количество подходов (степпер −/+) и повторения в каждом подходе.
- **Перенос веса**: при назначении тренировки на новый день вес подтягивается с прошлого раза,
  под упражнением подсказка «Прошлый раз (дата): 60 кг · 10/10/9».
- **Статистика** (вкладка «Статистика»): график роста весов «горой» (area+line). Режимы —
  по упражнению (вес по датам) и по тренировке (среднее + медиана по всем упражнениям). Плитки:
  последний, максимум, рост, медиана. Ниже — история по датам.
- **Синхронизация между устройствами** через Telegram CloudStorage (привязано к твоему аккаунту,
  без бэкенда). У каждого пользователя своё облако — можно давать друзьям.
- **Дизайн** — тёмно-синий + белый в духе NN Fitness. Тап по пустому месту закрывает клавиатуру.

Всё в одном файле `index.html` (без сборки). Данные: `localStorage` (локальный кэш) + Telegram
CloudStorage (синхронизация, только внутри Telegram).

## Файлы
- `index.html` — само мини-приложение.
- `bot.js` — бот: ставит кнопку «Открыть» и отвечает на `/start` (Node.js, без зависимостей).
- `package.json` — запуск бота (`npm start`).

## Модель данных (localStorage ключ `gymDiary.v3`)
```
workouts: [ { id, name, exercises: [ { id, name } ] } ]          // шаблоны тренировок
sessions: {
  "YYYY-MM-DD": {
    workoutId,                                                   // выбранная тренировка
    exercises: [ { id, name } ],                                 // снимок на момент назначения
    entries: { <exId>: { weight, reps: [ ... ] } }               // цифры по id упражнения
  }
}
```
CloudStorage: ключ `workouts` + по ключу на день `s:YYYY-MM-DD` (инкрементальная синхронизация).
История каждого дня — снимок упражнений, поэтому правка шаблона не переписывает прошлые записи.

## Бот (опционально, для приветствия на /start)
Кнопка «Открыть» работает без запуска кода (она хранится на стороне Telegram). Для `/start`-приветствия
нужен запущенный `bot.js` (Node.js 18+):
```powershell
$env:BOT_TOKEN="ТОКЕН_ОТ_BOTFATHER"
$env:WEBAPP_URL="https://skysx67.github.io/gym-diary/"
node bot.js
```

## Локальная проверка приложения
```bash
python -m http.server 5177
```
Открыть `http://localhost:5177/index.html`. В обычном браузере работает `localStorage`;
синхронизация CloudStorage — только внутри Telegram.
